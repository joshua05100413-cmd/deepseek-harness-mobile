# DSHgo

把电脑上的 DSH 工作台带到手机：点开 App 就是电脑上正在跑的实时会话，可看可操作。
**隧道内核已内置在 App 中**（基于 libtailscale 源码级集成），无需安装任何第三方 VPN 应用。

- 作者：**Fa2517**（[bilibili](https://space.bilibili.com/330037645)）
- 包名：`com.dsh.remote`
- 当前版本：v1.0 · **完全开源**

## 一、这是什么

| 特性 | 说明 |
|---|---|
| 内置加密隧道 | Tailscale 内核直接编译进 APK，App 内登录、App 内建隧道，永无第二窗口 |
| 万能抓取 | 隧道接通后自动扫描识别远程 DSH 工作台并直连（不挑主机名/端口） |
| 实时监控 | 看到的就是电脑上正在跑的会话、子智能体、后台任务（实时刷新） |
| 原生外观 | 开机动画、原生顶栏、原生弹窗；无地址栏、无浏览器痕迹 |
| DSHgo / ZCode go 双模式 | 顶栏一键切换：DSHgo 走隧道看工作台；ZCode go 直连 ZCode 远程（自动开关隧道） |
| 站点小窗 | 地球图标弹窗查看本地监控页/任意网页（可选开关，默认关闭）；本地页面里的 127.0.0.1 请求自动穿隧道回电脑 |
| 移动端适配 | 竖屏布局、桌面式弹窗自动重排、侧边栏点空白关闭、切换会话不弹键盘 |
| 语音输入 | 自动申请麦克风权限，语音输入开箱即用 |
| 多主题 | 深邃黑 / 深海蓝 / 紫罗兰 / 纸感白 / 雾灰蓝，一键切换全局生效 |
| 弱网优化 | 连接状态可视化（绿/黄/红）、断线自动重连、历史缓存秒开、WS 保活 |

> **已知限制**：设置中的「窄屏自动收起侧边栏」为预留开关，**功能未实现**，打开/关闭均不影响使用，后续版本补齐。

## 二、首次使用（就三步）

1. **电脑端**：安装 [Tailscale](https://tailscale.com/)（与手机同一账号）→ 进入 `pc-plugin/` 目录**双击 `install.bat`** → **重启 dsh**。
   - 插件自动发布工作台到你的 Tailscale 网络，无需手动跑任何脚本。
2. **手机端**：安装 `DSHRemote.apk` → 打开 → 点「**登录账号**」完成 Tailscale 登录（仅此一次）。
3. 系统弹出 VPN 授权 → 点**允许**；再弹麦克风权限 → 点**允许**（语音输入用）。

之后每次打开 App：**自动建立隧道 → 自动发现电脑 → 自动进入工作台**，零步骤。

## 三、日常使用

- **顶栏**：DSHgo｜ZCode go 双模式切换；● 状态点（绿=已连接 / 黄=连接中 / 红=断开）；⟳ 刷新；🌐 站点小窗（需先在设置开启）；⚙ 设置
- **安卓手势**：点空白区域自动收起侧边栏/弹出面板；返回键先关侧边栏再后退/挂后台
- **会话切换**不会弹键盘；点输入框才弹，打字体验原生
- **横屏**：设置 → 屏幕方向 可切横屏或跟随系统（平板横屏原生适配）

## 四、设置说明

**连接**：隧道登录状态（登录/登出）、目标服务器（自动发现/手动）、自动发现目标、重新发现、启动自动加载、连接诊断
**显示**：主题风格（5 套）、网页缩放、屏幕方向、全屏沉浸、屏幕常亮、窄屏自动收起侧边栏（**未实现**，预留开关不影响使用）、桌面版模式
**行为**：返回键挂起、外链用系统浏览器、断线自动重连
**数据**：清除网页缓存、清除登录凭证
**关于**：版本、作者、使用帮助、开源说明

## 五、常见问题

- **一直"正在连接/等待电脑端"**：电脑没开机、dsh 没运行或插件未安装（`pc-plugin/install.bat`）；点 ⟳ 重试
- **发现不到目标**：设置 → 重新发现目标；或手动填地址（如 `https://你的电脑名.ts.net/`）
- **连接慢**：首次加载需下载界面资源（已启用压缩）；之后走缓存会快很多。手机与电脑同 WiFi 时 Tailscale 自动走直连，速度最快
- **换账号**：设置 → 隧道登录状态 → 退出登录
- **语音不能用**：系统设置里给 DSHgo 麦克风权限（App 首次启动会自动申请）

## 六、电脑端要求

- Windows，已登录 Tailscale（开机自启即可）
- 已安装 dsh（DeepSeek Harness 桌面版）
- 运行一次 `pc-plugin/install.bat` 并重启 dsh；之后插件自动守护整条链路
  （端口自愈：进程挂掉 30 秒内自动重启；dsh 升级不影响插件）

## 七、隐私与安全

- 全程走 Tailscale 加密隧道（WireGuard），仅你自己的设备可达
- 登录凭据由 App 内核经 Android Keystore 加密存储，不出设备
- 万能抓取只在你的 tailnet 内部探测，不发起任何外部请求
- 本 App 不收集、不上传任何个人信息

## 八、项目结构

```
phone-app/                     # 手机端（Android，无 Gradle）
├─ AndroidManifest.xml         # 清单（VPN 服务、麦克风、前台服务）
├─ build.bat                   # 一键打包（aapt2+javac+d8+apksigner）
├─ build-env.example.bat       # 工具链路径模板（复制为 build-env.bat 使用）
├─ src/com/dsh/remote/
│  ├─ MainActivity.java        # 主界面：连接流程、双模式切换、站点小窗、适配注入
│  ├─ SettingsActivity.java    # 设置界面
│  ├─ BootAnimView.java        # DSHgo 开机动画
│  ├─ Tunnel.java              # libtailscale 引擎封装 + localapi（登录/状态/连接）
│  ├─ TailscaleVpnService.java # 自有 VpnService（隧道建立与底层网络切换）
│  ├─ SecureStore.java         # AppContext 实现（Keystore 加密存储）
│  ├─ Discovery.java           # 万能抓取（tailnet 端点自动识别）
│  ├─ LocalForwarder.java      # 本机服务转发（图片/文件资源通道）
│  ├─ ThemePalette.java        # 5 套主题
│  └─ Prefs.java               # 设置存储
└─ res/                        # 图标、启动图、矢量图标

pc-plugin/                     # PC 端（dsh 插件，装完即用）
├─ install.bat / install.ps1   # 一键安装（挂进所有 dsh profile）
├─ lib/index.js                # 插件主体：守护 minter/bridge/tailscale serve
└─ bridge/                     # 手机流量桥接（登录自动签发、本地端口穿透、站点串流）
```

隧道内核来自开源项目 tailscale-android 的 libtailscale（gomobile bind 产出 AAR 后集成），
构建方法见 build.bat 注释；内核编译产物为 `libgojni.so`（arm64-v8a / armeabi-v7a）。

## 十、DSHgo 开机动画

启动时：DSH 图标居中亮相 → 整体向左拉动 → 依次拉出 DSHgo 名称、
作者头像与 Fa2517 署名、粉色 bilibili 标（方向：从右往左），
底部显示联系提示。全程覆盖"连接中"时段，进入工作台时平滑淡出。

## 十一、站点小窗

设置 → 站点小窗（默认关闭）开启后，顶栏地球图标弹出站点列表，
点选后以**悬浮小窗**显示（不占用主界面，点空白或 ✕ 关闭）：
- 本地页面：`https://你的电脑名.ts.net/__site/文件名.html`
  （把 html 文件放在电脑桌面即可被串流到手机）
- 本地页面里的 `127.0.0.1:端口` 请求会**自动穿隧道**回到电脑本机，
  任何本地监控面板/状态页无需改动即可在手机上完整运行
- 远程网页：任意 https 地址

## 十二、弱网优化

- 连接状态可视化：顶栏 绿/黄/红 + 状态字（断连不再默默发生）
- 自动重连：检测"连接异常/请重试"自动恢复
- fetch 自动重试（2 次退避）+ 历史秒开缓存（断网时显示缓存内容）
- 启动预热（页面在动画期间后台加载）+ WS 保活 + gzip 压缩
