# V1.2 本地验收（2026-10-24）

针对 [issue #4](https://github.com/just-a-FA-for-name/DSHgo/issues/4) 修复 Android 应用专用 VPN 和 MagicDNS 下发。保留完整域名的 TLS / SNI / 证书校验，不放行错误证书、不改用 HTTPS IP 地址。Android versionCode 4，versionName 1.2，沿用原有签名。

## 安装与反馈

- 手机覆盖安装本目录 DSHgo-v1.2.apk；已在测试机安装并启动最终非调试版。
- 电脑解压 DSHgo-pc-plugin-v1.2.zip，进入 pc-plugin 双击 install.bat，随后重启 dsh。上传传输需要两端同时更新。
- 真实运营商 5G 由用户测试。复现后进入设置 → 故障排查 → 导出诊断包，选择保存位置，将 ZIP 与复现时间、操作一并反馈；无须 root 或 ADB。
- 设置 → 显示 → 主题风格 → 大肥鱼 · 海盐蓝；原有五种主题保留，切换不销毁 WebView。顶部连接徽章、侧栏、输入卡片、连接/错误页均有主题元素。
- 开屏保留从右往左的拉出过程，约 5 秒节奏；作者头像、哔哩哔哩和 FA 2517 是同步移动的一整组。采用浅蓝渐变背景。

## 自动与真机验证

- Node 桥接/上传 16 项、真 Chromium 浏览器手机适配 18 项（含父用例），合计 34 项全部通过。覆盖流式 SSE、gzip、HTML 提前挂载、缓存、取消、只读重试、POST 不重放、WebSocket 重置、并发发现、重复安装、抽屉宽度、返回键、草稿/附件保留及主题切换。
- 随机 24 MiB 上传验证 SHA-256；覆盖半截分块、丢失创建/分块确认、12 次并发创建重试共用一个上传槽、错误 offset、登录隔离、未完成禁止提交、最终回执丢失/失败不重放 POST。
- 静默断开的 TCP 分块在空闲超时后回滚并释放 busy。socket 关闭早于磁盘回滚结束，测试以有界轮询验证最终解除；客户端也会等待 busy 结束。
- SM-F7310（Android API 35）：VPN 配置包含 MagicDNS 100.100.100.100 和 /32 路由，允许 UID 仅为 DSHgo（含系统分身范围）；完整 .ts.net HTTPS 工作台正常加载。
- 授权的空白测试对话：24 MiB+17 字节文件得到 DSH 原生成功回执，两张合成 PNG 加载成功；16 MiB+19 字节在短暂断连后完成。上述大文件通过标准 File/change 注入；两端升级生效后，另以 Android 原生系统文件选择器选择 4 MiB+31 字节合成文件，上传成功成为草稿附件，且免 root 导出日志记录到进度与完成事件。
- Wi-Fi 关闭/恢复：当前 document 和未发送的合成草稿保留。真机切换大肥鱼主题后，document/草稿也保留。
- 最终非调试 APK：v2/v3 签名校验通过，覆盖安装成功并显示已连接；run-as 确认非 debuggable。测试辅助 APK 已卸载。

## 高难度网络模拟

仅作用于 DSHgo UID 和其专用 VPN 接口，不读取 peers/连接历史。阻断 IPv4/IPv6 非 DNS UDP，使通常的 UDP 直连不可用，测试 relay 路径；规则计数器和 qdisc 统计均实际命中。

| 阶段 | 延迟 ± 抖动 | 丢包 | 限速 | 时长 |
|---|---|---|---|---|
| 中度受限 | 350 ± 200 ms | 10% | 768 kbit/s | 50 秒 |
| 随机断连 | 900 ± 600 ms | 25% | 192 kbit/s | 100 秒 |
| 极差网络+随机断连 | 1800 ± 1400 ms | 45% | 64 kbit/s | 100 秒 |
| 快速抖动断连 | 600 ± 500 ms | 15% | 512 kbit/s | 60 秒 |

另叠加 1% 重复、0.1% 损坏、12% 乱序及 45 秒完全阻断。自适应分块轮共 93 个采样，32 MiB+23 字节（33,554,455）最终成功；正常网络恢复后约 25 秒完成，document/草稿保持。极差阶段上传确实停滞，不能声称 45% 丢包、64 kbit/s 下持续可用。

进一步在外层 HTTPS（含中继/控制连接）做 6 秒 TCP reset、12 秒黑洞、20 秒 TCP reset，叠加 15% 丢包/抖动：修复前上传失败，网络恢复 120 秒后仍未完成；加入分块空闲超时与回滚后，同组测试 2 MiB+29 字节成功，网络恢复约 10 秒完成，document/草稿保留。阻断 UDP、对全部外层 HTTPS 加 20% 丢包后，冷加载约 32 秒挂载完成。

实际制造 Chromium 内部错误页，再恢复网络，观察到错误文档，随后约 10 秒恢复到编辑器及最新传输脚本，避免原先假 ready 卡住。

所有测试专用 IPv4/IPv6 链与 netem 已清理；设置了自动清理兜底。最终再次确认专用链不存在。

## 免 root 日志验证与隐私

- 使用 ACTION_CREATE_DOCUMENT，由用户选择位置保存 ZIP，不要求 READ_LOGS、root 或额外存储权限；不自动上传。
- 内容只有本应用数字状态、WebView/DNS/TLS/HTTP 错误码、粗粒度网络类型与上传失败分类；不导出系统 logcat、控制台原文、IP、域名、Cookie、Token、文件名或聊天。
- 默认开启，可关闭/清除。最多 3 份约 256 KiB JSONL 循环保存。15,000 次合成事件压力验证：保留 10,213 条、566,715 字节，关闭后不写入，未知事件拒绝，导出字段全为数字。
- 调试与最终非调试版均实际通过系统保存文件界面导出，并检查 ZIP 完整性和数字字段。最终导出含 21 条事件，无敏感文本。
- 测试仅使用授权的新空白对话及合成文件，没有查看历史对话、连接历史或个人文件。

## 实现范围与待验证

- 真实运营商 5G、各 DERP 节点、不同手机后台策略的长期稳定性尚待用户实测；模拟结果不能替代实际 5G。
- 断点恢复覆盖网络中断；App/WebView 被杀、电脑桥接重启、登录 Cookie 改变后，需要重新选择文件。桥接运行时清理 30 分钟未活动暂存；异常退出留下的系统临时目录 dshgo-upload-* 不保证自动回收。
- 32 KiB–1 MiB 自适应分块，从 128 KiB 开始。仅适配当前 dsh-file-upload Worker 的 Blob 上传；ReadableStream 保留单次流式协议，图片仍用 DSH 自有图片消息协议。
- 2 GiB 是协议上限，不是实测结果；本次真机最大约 32 MiB。DSH、模型或磁盘可能另有限制。
- 此 WebView 的 crossOriginIsolated 仍为 false，不能把 COOP/COEP 响应头当成 SharedArrayBuffer 已启用。
- 本机电脑插件文件已更新并核对 SHA-256；核实桥接子进程身份后单独重启，运行中的入口已返回最新版含诊断观察的 transport.js。
