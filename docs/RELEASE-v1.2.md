# DSHgo V1.2

这次集中修复了很多连接、弱网恢复和文件上传问题，也补上了免 root 诊断日志，并重新整理手机竖屏触控界面。

**升级时请同时更新手机 APK 和电脑端插件。** 手机安装 `DSHgo-v1.2.apk`；电脑下载并解压 `DSHgo-pc-plugin-v1.2.zip`，进入 `pc-plugin` 双击 `install.bat`，完成后重启 dsh 桌面版。

## 修复了什么

- **5G / relay 下卡在“正在载入”**：针对 issue #4，向 Android 显式下发 MagicDNS，修复隧道通了但 `.ts.net` 域名无法解析的问题；保留正确域名、SNI 和证书校验。
- **隧道影响其他软件**：改为 DSHgo 应用专用 VPN，其他 App 继续走自己的网络。
- **频繁断连、网络切换后恢复不正常**：改进物理网络选择、上游 DNS 更新和连接恢复，避免正常恢复过程反复整页重载。
- **弱网下功能未挂载、白屏或看起来像“退回旧版本”**：禁用工作台 HTML/API 的陈旧缓存，提前安装传输和手机适配，修复慢速加载时的重载干扰，并识别 Chromium 内部错误页。
- **“显示已连接”但实际发不出去**：下行 WebSocket 心跳不再掩盖 HTTP 上行失败，连接提示更接近实际状态。
- **文件上传断一次就卡住**：新增自适应分块与网络中断续传，修复创建/分块确认丢失、半截 TCP 一直占用上传通道等问题。
- **桥接和实时连接问题**：修复端口发现竞争、错误端口猜测、WebSocket Host/Origin 不一致、流式转发和缓存等问题；发送命令不会因网络重试被重复执行。

## 新增了什么

- **文件分块续传**：分块从 128 KiB 开始，按网络自适应调整到 32 KiB–1 MiB，进度以已确认字节计算；电脑暂存采用流式落盘。
- **免 root 诊断日志**：设置 → 故障排查 → 导出诊断包。插卡手机出现问题后，可以直接导出 ZIP，并说明时间和复现操作。支持关闭与清除，不自动上传，不记录聊天、文件名、IP、域名、Cookie 或 Token。
- **可切换的大肥鱼主题**：顶部连接状态徽章、侧栏、输入卡片、连接/错误插画统一适配，原有主题保留；切主题不再销毁当前网页和草稿。
- **手机触控优化**：继续以手机竖屏使用为主，扩大顶栏点按区域、设置开关支持整行点按，刷新前提示草稿和上传风险。
- **开屏动画调整**：保留较慢的从右往左拉出；作者头像、哔哩哔哩和 FA 2517 同组同步出现，换用浅蓝渐变背景。

## 为什么电脑插件也要更新？怎么更新？

这里的插件是现有 **dsh-phone-remote 的 V1.2 升级版**，不是再装一套远程软件。它是手机与电脑工作台之间的桥接，负责登录转接、页面/实时连接转发，以及这次新增的电脑端分块暂存、续传和上传回执。

只更新 APK，手机端的 MagicDNS 和专用 VPN 修复会生效，但旧插件没有 V1.2 的续传接口及桥接修复，无法获得完整的新上传能力。**大文件上传、弱网恢复请两端一起更新。**

1. 电脑保持原有 Tailscale 安装和账号，无须重装 Tailscale。
2. 下载 `DSHgo-pc-plugin-v1.2.zip`，完整解压。
3. 打开解压出的 `pc-plugin` 文件夹，双击 `install.bat`。它会更新已有插件并注册到 dsh 的 profile；重复运行不会嵌套安装 `bridge/bridge`。
4. 退出并重新打开 dsh 桌面版，让桥接加载新版本。
5. 手机覆盖安装 `DSHgo-v1.2.apk`，再打开 DSHgo 连接。

默认不需要手改代码、重新配对或开放公网端口。若你原本使用自定义 Tailscale serve / 插件配置，请保留并检查自己的配置。

## 验证与已知限制

- 34 项连接、上传与真 Chromium 手机适配回归通过；最终非调试 APK 已在 SM-F7310 覆盖安装并启动，免 root 的系统保存 ZIP 流程也实际验证过。
- 测试涵盖随机丢包、抖动、乱序、限速、随机断连、外层中继连接重置和黑洞。约 32 MiB 文件在恢复正常网络后完成上传，草稿和当前页面保留。
- 极端 45% 丢包、64 kbit/s 阶段会停滞；不承诺这种条件下仍能流畅使用。真实运营商 5G、不同设备后台策略仍请继续反馈。
- 网络中断可续传；App/WebView 被杀、电脑桥接重启或登录身份改变后，需要重新选择文件。
- 分块适配当前 DSH 文件 Worker 的 Blob 协议；图片保留原有图片协议，本次验证了合成 PNG。不能据此宣称所有图片格式均已解决。
- 单文件协议上限 2 GiB，本次真机最大实测约 32 MiB，2 GiB 仍未压力验证。

更多测试范围见 [V1.2 验收记录](https://github.com/just-a-FA-for-name/DSHgo/blob/main/docs/V1.2验收记录.md)。大肥鱼图片署名与独立许可见 [素材许可](https://github.com/just-a-FA-for-name/DSHgo/blob/main/phone-app/ASSET-LICENSES.md)。
